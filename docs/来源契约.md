# 资料提供方的格式

`/exhibits.html` 由联展方发出，列为公称展品、配置、实物登记号。`/holdings.json` 给登记号到物理件映射、可借地点、时窗及途经分钟。用途登记在 `/policy.csv`，同一套配置由多个实物件组成，逐件限制。 `/meetings.json` 给企业请求、可接受地点、演示区间、用途和跨用途修改。分钟区间左闭右开。
`/lend` 是保管方的借出页，按实际件与票据查到放行和应还地点。`/receive` 的查询按接收方、票据和交接轮次返回签认。演练中同型展示件有自己的实物编号，不能改变已放行的票据。
`/transfers` 是录入实物交接的网页，提交后可从借出和收件页查询。L27 只表示归还申请已受理。
`/ticket-book.json` 是已有交接票登记，保管地点以两边网页回读为准。
